# Fitnes — платформа управления фитнес-клубом и сетью

Собственная CRM + клубный софт + собственный серверный ИИ (Этап 1).

## Структура

- `docs/01_ТЗ_и_план/` — техническое задание (актуальная версия), последовательность разработки, диаграмма Ганта.
- `docs/02_Исходные_материалы/` — исходные пожелания: ТЗ v1.1–1.3 по 1С, «СОФТ», «Дополнения 1 и 2», переписка рабочей группы.

Код платформы будет добавляться по шагам согласно `docs/01_ТЗ_и_план/Последовательность_разработки_v1.0.md`.

## Как забрать на компьютер

```
cd C:\Users\Admin\Desktop\Fitnes
git clone git@github.com:AndreyBespalyy/Fitnes.git .
```
(если папка не пустая — клонировать во вложенную папку `repo` или выполнить `git init` + `git remote add origin ...` + `git pull origin main`).
