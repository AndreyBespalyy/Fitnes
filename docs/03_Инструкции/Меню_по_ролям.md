# Меню по ролям

Решение Андрея 15.11.2026: каждая роль видит в меню только своё. Собственнику — только отчёты (финансы, посещаемость, выплаты, проблемные моменты), без операционки.

Меняется только меню (`apps/web/src/roleMenu.ts`). Права ролей (`apps/api/src/roles.ts`) прежние: раздел, на который есть право, открывается по ссылке, из уведомления или по клику в отчёте. Несколько ролей у сотрудника — меню объединяется. Новая роль, которой нет в списке, видит всё, на что есть право.

**Проблемные моменты** (`/api/problems`): просроченные платежи, неудачные автосписания, согласования, расхождения в кассе за 7 дней, непробитые чеки, неутверждённая зарплата за прошлый месяц, низкие оценки клиентов, клиенты не ходят 14+ дней, абонементы без продления, заявки без ответа, просроченные задачи, отменённые занятия. По каждому пункту — число и сумма по клубам и переход в нужный раздел. Финансисту — только деньги, касса и зарплата.

**Выплаты** — ведомость зарплаты (тот же расчёт, что во вкладке «Зарплата» раздела «График и зарплата»), с выбором клуба прямо на странице.

«Загрузка» переименована в «Посещаемость». На рабочем столе собственника по умолчанию больше нет технического окна «Система».

## Поля внутри страниц (16.11.2026)

Кроме меню, внутри страниц роль видит только те поля, фильтры и блоки, с которыми работает. Что не может менять — не показывается полем.

- **Тренер.** В «Расписании» нет выбора тренера: видны только свои занятия (сервер тоже отдаёт только их, чужое занятие не открыть и на него не записать). В «Моих клиентах» — только свои клиенты, без колонки «Клуб». В карточке клиента — телефон и абонементы; продажные и денежные блоки (автосписание, карты, депозит, баллы, семья, обзвон, допродажи, «Приведи друга», сделки, задачи, обращения, история, договор) не показываются и сервером не отдаются.
- **Менеджер, РОП.** Вкладка «Настройки» в «Отделе продаж» есть только у управляющего и собственника (они её меняют). «План продаж» и «Нормы KPI» у РОПа — текстом, без полей ввода.
- **Менеджер, ресепшн.** В «Тарифах» правила клуба — короткой сводкой, без полей; настройки бонусной программы не показываются. В «Кассе» у ресепшна — только журнал чеков, без настроек кассы.
- **Все сотрудники одного клуба.** Вместо выпадающего списка с одним клубом — просто название клуба. Колонка «Клуб» в списке клиентов — только если видны клиенты нескольких клубов. Переключатель из одной вкладки (например, «Неделя» или «Моё») не показывается.
- **Помощь.** В списке инструкций — только те, что относятся к разделам роли, плюс общие (рабочий стол, мессенджер, телефон и т.п.).

## Исправления после проверки CRM (17.11.2026)

Отчёт с находками: `/mnt/project-files/Аудит_CRM/Проверка_CRM_17.11.2026.md`. Сделано по рекомендациям:

- **«Мои задачи» у всех ролей.** Ресепшн, тренер и финансист получают шаги процессов и задачи из советов — теперь у них есть «Мои задачи» в меню, плитка «Мои задачи» на рабочем столе и кнопка внизу экрана телефона. Выполнить задачу может исполнитель или тот, кто её поставил; выполненный шаг процесса сразу передаёт следующий шаг. «Бизнес-процессы» открываются всем: без права работы в CRM — только процессы со своими шагами, без запуска и шаблонов.
- **Закрытый раздел.** Если кнопка, ссылка или уведомление ведёт в раздел, закрытый для роли, вместо пустой страницы — плашка «Раздел не для вашей роли» и кнопка «На главный экран». Дядя Витя больше не даёт ресепшну кнопку «Открыть звонки» (вместо неё «Позвонить» по каждому пропущенному) и не даёт кнопку «Разбор недели» тем, кому раздел закрыт.
- **«+ Задача».** В «Задачах» и в карточке клиента — новая задача себе или коллеге своего клуба; в карточке у задачи есть «Выполнить». Если в клубе нет сотрудника нужной роли, совет «Начать» прямо пишет, кому ушла задача.
- **Скрипты звонков** — «Отдел продаж → Скрипты звонков», по каждому клубу. Правят РОП и управляющий; по ним работают «Показать скрипт звонка» и разборы Дяди Вити. Адрес подставляется из карточки клуба (`{адрес}`). Общий чек-лист в «Настройках клуба» остаётся для оценки в «Обзорах → Качество звонков».
- **РОП** (право `sales.manage`): план по менеджерам, нормы KPI, правила «Отдела продаж», скрипты — в своём клубе. План клуба — у управляющего и собственника. Черновиков настроек клуба у РОПа больше нет.
- **Управляющий:** в меню «Выплаты» и «Статистика сотрудников» (сотрудники своего клуба).
- **Собственник:** «Товары» в блоке «Настройки». Разделы, которым нужен один клуб («Обзоры», «Настройки клуба», «Разбор недели», «Бизнес-процессы», «Отдел продаж», «График и зарплата»), при «Все клубы» сами показывают первый клуб и кнопки других клубов.
- **Финансы:** собственник открывает их на «ДДС и план-факт», финансист — на «Журнале платежей»; «Касса смены» у них последней вкладкой.
- **Главный экран и панель телефона по роли:** ресепшн начинает с «Ресепшна», тренер — с «Моего дня». Панель телефона: управляющий — Главная, Проблемы, Задачи, Финансы; финансист — Главная, Финансы, Проблемы, Прибыль; РОП — Главная, Продажи, Задачи, Чаты; ресепшн — Ресепшн, Чаты, Клиенты, Задачи; тренер — Мой день, Занятия, Клиенты, Задачи.
- **Названия:** «Проходы» → «Проходы и турникеты»; «Касса» → «Чеки» у ресепшна и «Касса и чеки» у управляющего; «Чему научился помощник» → «Чему научился Дядя Витя».
- **Лиды:** сначала список, форма — по кнопке «+ Лид». В «Обзорах → Отдел» — кнопка на общий «Рейтинг менеджеров».
- **Мелочи:** у ресепшна и тренера на рабочем столе нет «Словаря метрик», «Настроить» и выгрузок; пустые «Товары» у тех, кто не может добавлять, говорят, к кому обратиться; цена товара меняется полем в строке.
