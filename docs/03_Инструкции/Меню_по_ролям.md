# Меню по ролям

Решение Андрея 15.11.2026: каждая роль видит в меню только своё. Собственнику — только отчёты (финансы, посещаемость, выплаты, проблемные моменты), без операционки.

Меняется только меню (`apps/web/src/roleMenu.ts`). Права ролей (`apps/api/src/roles.ts`) прежние: раздел, на который есть право, открывается по ссылке, из уведомления или по клику в отчёте. Несколько ролей у сотрудника — меню объединяется. Новая роль, которой нет в списке, видит всё, на что есть право.

**Проблемные моменты** (`/api/problems`): просроченные платежи, неудачные автосписания, согласования, расхождения в кассе за 7 дней, непробитые чеки, неутверждённая зарплата за прошлый месяц, низкие оценки клиентов, клиенты не ходят 14+ дней, абонементы без продления, заявки без ответа, просроченные задачи, отменённые занятия. По каждому пункту — число и сумма по клубам и переход в нужный раздел. Финансисту — только деньги, касса и зарплата.

**Выплаты** — ведомость зарплаты (тот же расчёт, что во вкладке «Зарплата» раздела «График и зарплата»), с выбором клуба прямо на странице.

«Загрузка» переименована в «Посещаемость». На рабочем столе собственника по умолчанию больше нет технического окна «Система».

## Поля внутри страниц (16.11.2026)

Кроме меню, внутри страниц роль видит только те поля, фильтры и блоки, с которыми работает. Что не может менять — не показывается полем.

- **Тренер.** В «Расписании» нет выбора тренера: видны только свои занятия (сервер тоже отдаёт только их, чужое занятие не открыть и на него не записать). В «Моих клиентах» — только свои клиенты, без колонки «Клуб». В карточке клиента — телефон и абонементы; продажные и денежные блоки (автосписание, карты, депозит, баллы, семья, обзвон, допродажи, «Приведи друга», сделки, задачи, обращения, история, договор) не показываются и сервером не отдаются.
- **Менеджер, РОП.** Вкладка «Настройки» в «Отделе продаж» есть только у управляющего и собственника (они её меняют). «План продаж» и «Нормы KPI» у РОПа — текстом, без полей ввода.
- **Менеджер, ресепшн.** В «Тарифах» правила клуба — короткой сводкой, без полей; настройки бонусной программы не показываются. В «Кассе» у ресепшна — только журнал чеков, без настроек кассы.
- **Все сотрудники одного клуба.** Вместо выпадающего списка с одним клубом — просто название клуба. Колонка «Клуб» в списке клиентов — только если видны клиенты нескольких клубов. Переключатель из одной вкладки (например, «Неделя» или «Моё») не показывается.
- **Помощь.** В списке инструкций — только те, что относятся к разделам роли, плюс общие (рабочий стол, мессенджер, телефон и т.п.).
