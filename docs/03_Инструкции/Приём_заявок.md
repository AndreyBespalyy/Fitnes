# Приём заявок с сайта, Tilda, VK и Авито

Где: раздел **Приём заявок**. Настраивают администратор системы (для любого клуба) и управляющий (для своего клуба).

Каждая заявка сразу становится лидом клуба: с источником для отчётов, проверкой на дубли по телефону во всей сети, назначением менеджера и задачей первого ответа — так же, как заявка, введённая вручную.

## Как подключить
Выберите, откуда принимать заявки, и нажмите «Создать подключение». Система покажет **ссылку подключения** — она показывается один раз. Если ссылка потерялась или попала не туда, нажмите «Новая ссылка»: старая сразу перестанет работать.

**Форма на сайте.** Под ссылкой — готовый код формы (имя, телефон, согласие). Вставьте его на страницу сайта. Если на сайте своя форма, пусть она отправляет поля name, phone, email, comment методом POST на ссылку. Метки UTM из полей utm_* сохраняются в лиде.

**Tilda.** Настройки сайта → Формы → Другое → Webhook, вставьте ссылку в поле «Адрес» и нажмите «Добавить». Tilda пришлёт проверочный запрос — в журнале он будет отмечен как «проверка». Затем в нужных формах отметьте сервис Webhook. Поля Name, Phone, Email и метки UTM распознаются сами, остальные поля попадут в комментарий. Повторная отправка той же заявки не создаёт второй лид.

**ВКонтакте (формы сбора заявок).** В сообществе: Управление → Работа с API → Callback API. Вставьте ссылку в поле «Адрес». Строку, которую VK просит вернуть, впишите в «Строку подтверждения» у подключения (кнопка «Настройки»), сохраните и нажмите «Подтвердить» в VK. Задайте в VK «Секретный ключ» и впишите его сюда — запросы без ключа отклоняются. На вкладке «Типы событий» отметьте «Формы сбора заявок: новая заявка». Имя, телефон и ответы на вопросы формы попадут в лид, у клиента сохранится ссылка на страницу VK.

**Авито (сообщения).** Client ID и Client Secret — в кабинете Авито: «Для профессионалов» → «Интеграции». Впишите их при создании и нажмите «Подключить Авито». Первое сообщение покупателя за день по каждой переписке становится заявкой с текстом сообщения и номером объявления; ответы клуба заявок не создают. Отвечать покупателю — в мессенджере Авито.

## Защита
- Ссылка подключения — секрет: по ней принимаются заявки только в этот клуб. Её можно выключить или перевыпустить.
- С одного адреса — не больше 10 заявок за 10 минут на подключение (для сайта и Tilda), дальше форма просит попробовать позже.
- Скрытое поле website в форме сайта ловит роботов: такие заявки отмечаются «пропущено».
- Секретный ключ VK и Client Secret Авито хранятся зашифрованными и не показываются.

## Журнал приёма
Последние 50 событий: новый лид, дубль, проверка, пропущено, ошибка (например, неверный телефон — форма на сайте покажет клиенту понятный текст), лимит. По имени клиента открывается его карточка.

Для своих интеграций по-прежнему работает приём по API с ключом источника: `POST /api/v1/leads` с заголовком `Authorization: Bearer <ключ>`.
