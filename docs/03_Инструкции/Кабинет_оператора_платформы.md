# Кабинет оператора платформы

Пункт 19 списка «20 улучшений». Сети-клиенты теперь ведутся в браузере по адресу **/platform** (например, https://app.amoglobal.ru/platform), а не командами на сервере. С кабинетом подключение новой сети и выставление счетов не требуют разработчика.

## Вход

Это отдельный вход для команды платформы. Сотрудники клубов в него не попадают, а оператор не видит рабочих экранов клубов.

Первого оператора создают на сервере командой:

```
docker compose exec api npm run platform -w apps/api -- operator add <логин> "ФИО"
```

Команда покажет временный пароль, при первом входе его нужно сменить. Там же можно выдать новый пароль (`operator reset <логин>`) и закрыть доступ (`operator block <логин>`).

## Что есть в кабинете

**Сети.** Список сетей с тарифом и числом клубов, сотрудников и клиентов относительно лимитов. Там же последний вход, долг по счетам и открытые обращения. Сверху показаны итоги: сколько сетей и клубов, подписка в месяц и сумма неоплаченного.

**Подключить сеть.** Нужны название, ФИО и логин собственника. Система создаёт сеть, учётную запись собственника, источники заявок и лимиты согласований по умолчанию, а оператору один раз показывает временный пароль. Клубы собственник добавляет сам в разделе «Клубы».

**Карточка сети:**
- **Клубы и их состояние.** Действующие абонементы, посещения за неделю, последнее посещение, выручка за 30 дней и сбои: мессенджер с ошибкой, турникет не на связи.
- **Договор и тариф.** Номер, дата, тариф, плата в месяц, лимиты клубов и сотрудников, срок. Лимиты действуют сразу: сверх лимита сеть не добавит клуб или сотрудника, а работа существующих не блокируется.
- **Счета за подписку.** «Выставить за текущий месяц» в карточке или «Выставить счета за месяц» сразу всем сетям с платой по договору. Повторно счёт за тот же месяц не выставляется. Оплату отмечаете по выписке и указываете номер платёжки. Счёт можно аннулировать с причиной, но не удалить. Сеть видит свои счета.
- **Приостановить доступ.** Нужно указать причину, например долг. Сотрудники сети выходят из системы и не могут войти, пока доступ не возобновят. Данные при этом сохраняются.

**Поддержка.** Обращения из всех сетей: переданные платформе или все открытые. В карточке обращения видны раздел, версия приложения и технический журнал, оттуда же отправляется ответ. Ответ сразу виден автору в разделе «Помощь».

Все действия оператора записываются в журнал действий сети.

## Что дальше

Автооплата подписки картой появится после договора платформы с банком. Сейчас счета оплачиваются по реквизитам.
