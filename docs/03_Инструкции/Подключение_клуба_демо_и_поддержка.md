# Подключение нового клуба, демо-клуб и поддержка (шаг 18, часть 4)

## Подключение клуба по чек-листу
Раздел «Подключение клубов» видят собственник, управляющий (по своему клубу) и администратор системы.

Новый клуб подключается за 10 рабочих дней. Для каждого клуба есть чек-лист из 17 пунктов по дням:
1. **День 1.** Карточка клуба, юрлицо и реквизиты, готовый набор настроек, воронки продаж.
2. **День 2.** Цены в прейскуранте, управляющий, менеджеры и ресепшн.
3. **День 3.** Касса, онлайн-оплата.
4. **День 4.** Мессенджеры, турникеты.
5. **День 6.** Перенос клиентов из прежней системы, план продаж.
6. **День 7.** График смен на неделю вперёд.
7. **День 8.** Обучение сотрудников.
8. **День 9.** Пробная продажа, чек и договор.
9. **День 10.** Первый рабочий день.

Большинство пунктов система отмечает сама, когда видит данные: например, появилось юрлицо, касса или план. Такие пункты нельзя отметить вручную, чтобы чек-лист не расходился с настоящим состоянием.

Пункты «Обучение» и «Первый рабочий день» отмечаются кнопкой «Сделано». Необязательные пункты (онлайн-оплата, мессенджеры, турникеты, перенос данных) можно отметить «Не нужно», указав причину.

Срок каждого пункта считается от даты «Начало подключения», без суббот и воскресений. Просроченные пункты подсвечиваются красным. Кнопка «Открыть» ведёт в нужный раздел. Все отметки пишутся в журнал.

## Демо-клуб
Собственник или администратор системы может создать демо-клуб — на абонементах или на подписке. В нём:
- вымышленные клиенты с пометкой «(демо)» и телефонами +7 900 000-…;
- заявки за 4 недели, продажи, оплаты, посещения и план месяца.

Для чего он нужен:
- показать систему;
- обучить новых сотрудников, не трогая настоящих клиентов.

Демо-клуб не входит в цифры сети на рабочем столе и в ограничение тарифа. Его цифры видны только при выборе самого демо-клуба.

Кнопка «Закрыть демо-клуб» скрывает его из списков. Данные не удаляются, потому что денежные записи в системе не стираются. После этого можно создать новый демо-клуб.

## Помощь и поддержка
Раздел «Помощь» есть у всех сотрудников:
- **Инструкции** — все инструкции системы с поиском по словам.
- **Написать в поддержку** — тема, тип (вопрос, ошибка, предложение, доступ) и описание. Клуб и браузер подставляются сами. Не пишите в обращение телефоны и паспортные данные клиентов.

Сотрудник видит только свои обращения. Собственник и администратор системы видят все обращения сети и отвечают первыми. Если вопрос требует разработчиков, нажмите «Передать разработчикам».

Удалить обращение или сообщение из приложения нельзя.

Оператор платформы на сервере:
- `npm run platform -- support` — переданные обращения;
- `npm run platform -- answer 12 "текст"` — ответ, который придёт сотруднику с пометкой «Поддержка платформы».

## Договор с платформой и ограничения тарифа
Внизу раздела «Подключение клубов» видны номер договора, тариф, сколько клубов и сотрудников подключено и сколько разрешено.

Договор вносит только оператор платформы на сервере. Из приложения его поменять нельзя, это закрыто правами в базе:
```
npm run platform -- contract set --number П-1 --signed 2026-11-10 --plan Пилот --clubs 3 --users 40
npm run platform -- contract show
```

Когда лимит исчерпан, новый клуб или сотрудника не добавить: система покажет понятное сообщение. Работа уже подключённых клубов при этом не блокируется.

Если договора нет (как сейчас на пилоте), ограничений нет.
