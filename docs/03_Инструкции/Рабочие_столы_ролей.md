# Рабочие столы ролей

«Рабочий стол» открывается первым у каждого сотрудника. На нём окна с состоянием дел именно его роли. Каждая цифра, плитка и строка кликабельна: нажатие открывает раздел, где с этим можно работать, сразу с нужным фильтром. Стрелка › в углу плитки показывает, что она ведёт дальше.

## Что видит каждая роль

| Роль | Окна по умолчанию |
|---|---|
| Собственник | Эффективность дня, Сравнение клубов, План-факт месяца, Удержание клиентов, Отклонения и риски, Индекс лояльности, Конверсия по каналам, Система |
| Управляющий | Клуб сегодня, Эффективность дня, План-факт месяца, Отклонения и риски, Удержание клиентов, План менеджеров, Индекс лояльности, KPI сотрудников |
| Руководитель ОП | План менеджеров, Мой день, Удержание клиентов, Конверсия по менеджерам и каналам, KPI сотрудников, Мой план |
| Менеджер ОП | Мой день, Мой план, Мои показатели |
| Ресепшн | Ресепшн сегодня |
| Финансист | Финансы сегодня, Эффективность дня, План-факт месяца, Отклонения и риски |
| Тренер | Мои занятия |
| Администратор системы | Система |

Набор меняется во вкладке «Настроить». Собственник там же задаёт стандартный набор для каждой роли. Если сотрудник раньше настроил свой набор, новые окна добавляются кнопкой в «Настроить».

## Новые окна и куда ведёт каждая цифра

**Клуб сегодня** (управляющий): посещения → «Проходы», отчёт; занятия и запись → «Расписание»; новые лиды → «Лиды»; продажи → «Финансы», журнал платежей; ждут согласования → «Финансы», согласования; непрочитанные сообщения → «Переписка», непрочитанные; кассовые смены → «Финансы», касса смены. Список занятий на сегодня: нажатие открывает занятие с записанными клиентами.

**Удержание клиентов** (собственник, управляющий, РОП): заканчивают за 14 дней без продления → «Кому звонить», горячий список; досрочное продление, кампании возврата, ушедшие за 3 месяца, индекс лояльности → соответствующие вкладки «Возврата клиентов»; недовольные ждут звонка → «Задачи».

**Мой день** (менеджер, РОП): просроченные и сегодняшние задачи → «Задачи»; лиды без первого ответа → «Лиды» с фильтром «Ждут первого ответа»; кому звонить → «План дня»; встречи и сделки → «Сделки»; непрочитанные в моих чатах → «Переписка», мои. Ближайшие задачи: нажатие открывает карточку клиента.

**Ресепшн сегодня**: посещения → «Проходы», ресепшн; занятия → «Расписание»; кассовая смена → «Финансы»; лиды; сообщения. Списки «Предложите продление» (абонемент заканчивается за 3 дня) и «Пришли с долгом» — нажатие открывает карточку клиента.

**Финансы сегодня** (финансист): поступления → журнал платежей; расходы; просроченные долги; неудачные автосписания → онлайн-оплаты; согласования; открытые смены (красным, если смена не закрыта больше 16 часов); не сверено с банком → сверка; зарплата → ведомость.

**Мои занятия** (тренер): занятия сегодня и на 7 дней → расписание с фильтром «мои»; прошедшие занятия без отметки посещения (красным — их нужно отметить, иначе они не попадут в зарплату); проведено за месяц → «График и зарплата».

**Система** (администратор, собственник): клубы; клубы с незавершённым подключением → «Подключение клубов»; сотрудники без роли и с временным паролем → «Сотрудники»; открытые обращения → «Помощь», поддержка; незавершённый перенос из 1С.

**Старые окна** теперь тоже кликабельны: плитки «Эффективности дня» ведут в финансы, лиды, проходы и раскрывают план до клиентов; клуб в «Сравнении клубов» переключает рабочий стол на этот клуб; каждая строка «Отклонений и рисков» ведёт в свой раздел; имя сотрудника в KPI открывает его обзор; показатели менеджера ведут в звонки, переписку, сделки, задачи и лиды.

Ссылки из утренней сводки в Telegram тоже открывают раздел сразу с фильтром, например `?tab=finance&view=debts`.
