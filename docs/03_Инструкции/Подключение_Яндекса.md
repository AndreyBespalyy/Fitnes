# Подключение Яндекса: расшифровка звонков и ИИ-помощник

Что даёт: записи разговоров расшифровывает Yandex SpeechKit, итоги разговоров и «Коротко о ситуации» пишет YandexGPT.
Без ключей всё работает, но «Коротко о ситуации» собирается по правилам (только факты), а записи звонков ждут подключения.

Стоимость на ноябрь 2026 (с НДС): расшифровка ≈0,61 ₽ за минуту записи, при 3 часах разговоров в день ≈3 300 ₽ в месяц на клуб.
YandexGPT оплачивается по объёму текста, ориентир — несколько тысяч рублей в месяц на клуб.

## Шаги (делает владелец аккаунта, 15 минут)

1. Зайдите на console.yandex.cloud под рабочим аккаунтом Яндекса и создайте платёжный аккаунт **на юрлицо** (нужен договор с Яндексом: он же — поручение на обработку персональных данных по 152-ФЗ).
2. Создайте каталог, например `fitnes`. Скопируйте его идентификатор (строка вида `b1g...`) — это `YANDEX_FOLDER_ID`.
3. В каталоге: «Сервисные аккаунты» → «Создать». Имя `crm`, роли: `ai.speechkit-stt.user` и `ai.languageModels.user`.
4. Откройте созданный аккаунт → «Создать новый ключ» → «Создать API-ключ». Скопируйте секрет — это `YANDEX_API_KEY` (показывается один раз).
5. Пришлите оба значения Claude в тред проекта или впишите сами на сервере в `/opt/fitnes/deploy/.env`:
   ```
   YANDEX_API_KEY=...
   YANDEX_FOLDER_ID=...
   ```
   и перезапустите: `cd /opt/fitnes/deploy && docker compose up -d`.
6. Проверка: раздел «Звонки» → статус ИИ должен показать «Yandex SpeechKit / YandexGPT». В окне «Коротко о ситуации» внизу появится «Составил ИИ-помощник (YandexGPT)».

## Что важно по 152-ФЗ

- Предупреждайте клиентов о записи разговора (автоинформатор АТС: «разговор записывается»).
- Телефоны и e-mail клиентов в YandexGPT не передаются: система заменяет их на «[телефон]» и «[e-mail]».
- Записи звонков АТС должна сохранять в MP3 (или WAV/OGG) — другие форматы SpeechKit не принимает.
