# Автотесты интерфейса

Пункт 13 списка «20 улучшений». Кроме проверок сервера (около 220 тестов), теперь есть 10 сценариев, которые проходят в настоящем браузере так, как это делает сотрудник: открывают страницу, нажимают кнопки, заполняют поля и проверяют результат в базе.

## Что проверяется

1. Вход с временным паролем: система требует сменить пароль, после смены можно работать.
2. Менеджер создаёт лид: клиент появляется, ставится задача первого ответа.
3. Продажа абонемента «Месяц безлимит» в карточке клиента и оплата картой.
4. Ресепшн: поиск клиента по части телефона и проход.
5. Ссылка на карточку клиента открывается в новой вкладке, кнопка «Назад» возвращает к списку.
6. Расписание: запись клиента на занятие по ссылке на занятие.
7. Настройки клуба: черновик, проверка, утверждение и публикация.
8. «Сообщить о проблеме»: обращение с названием раздела попадает в поддержку.
9. Телефон: нижняя панель, меню «Ещё» и переходы.
10. Собственник: рабочий стол, прибыль, удержание, загрузка, финансы, использование и приём заявок открываются без ошибок.

В каждом сценарии дополнительно проверяется, что на странице не было ошибок.

## Когда запускаются

Автоматически при каждом изменении в GitHub (отдельная проверка «Автотесты интерфейса» рядом с «Проверкой»). Если сценарий сломался, это видно до того, как изменение дошло до клубов.

## Как запустить вручную (для разработчика)

```
npm run build
cd apps/api && npm run test:e2e
```

Нужны база с тестовыми данными (`npm run db:setup`) и Playwright 1.63 с Chromium. Сценарии работают на чистой тестовой базе и рабочие данные не трогают.
