# Как выгрузить пять отчётов из 1С для переноса

Инструкция для того, кто работает с 1С клуба. Каждый клуб выгружается отдельно.

## Общие правила

1. Любой отчёт или список в 1С можно сохранить в Excel. Сформируйте отчёт, затем выберите **Файл → Сохранить как** (или значок дискеты). Тип файла: **Лист Excel 2007 (.xlsx)**. CSV тоже подходит.
2. Старый формат **.xls** система не читает. Если 1С сохраняет только .xls, откройте файл в Excel и сохраните как .xlsx.
3. Период берите **за всю историю**: с первого дня работы клуба по сегодня.
4. Группировки в отчёте лучше выключить, чтобы каждая строка была одной записью. Название отчёта и строку «Итого» оставляйте: система их узнаёт. Итог платежей она сверяет с суммой строк.
5. Названия колонок можно не менять. Система сама находит нужные колонки по названиям, а вы проверяете это на экране «Карта полей».
6. Главное для связи отчётов между собой: **код клиента** (или хотя бы телефон) в каждом отчёте и **номер договора** в отчётах абонементов, платежей и долгов.

## Какие колонки нужны

Жирным выделены обязательные колонки, остальные желательны.

| Отчёт | Колонки |
|---|---|
| 1. Клиенты | Код клиента, **ФИО**, Телефон, Эл. почта, Дата рождения, Номер карты, Дата регистрации |
| 2. Абонементы и договоры | Код абонемента, Код клиента (или ФИО и телефон), Номер договора, Дата договора, **Вид абонемента**, **Дата начала**, Дата окончания, Стоимость, Остаток посещений, Состояние (действует, заморожен, аннулирован) |
| 3. Платежи | **Дата**, Номер документа, Код клиента, **Сумма**, Вид оплаты (наличные, карта, СБП, перевод), Операция (оплата или возврат), Номер договора |
| 4. Посещения | Код клиента, **Дата и время посещения**, Зона или занятие |
| 5. Остатки и долги | Код клиента, Номер договора, Задолженность, Аванс (деньги клиента на счёте) |

Возвраты можно давать минусом в колонке «Сумма» или словом «Возврат» в колонке «Операция».

## Что происходит дальше

1. В системе откройте раздел **«Перенос из 1С»**, выберите клуб и нажмите «Начать перенос».
2. Загрузите все пять файлов сразу. Система определит, какой отчёт в каком файле, и найдёт колонки.
3. Проверьте карту полей по каждому файлу и нажмите «Карта верна».
4. Нажмите «Пробный перенос». Он ничего не меняет в базе и показывает отчёт сверки:
   - сколько записей в 1С и сколько перенесётся;
   - что не переносится и почему;
   - деньги по месяцам и итог отчёта 1С против суммы строк.
5. Решите конфликты: например, телефон из 1С уже есть у клиента в системе.
6. Нажмите «Перенести в систему» и подтвердите паролем.
7. Выборочно проверьте 20–30 карточек знакомых клиентов. Если всё верно, нажмите «Принять перенос». До принятия перенос можно отменить целиком.

Повторная загрузка тех же файлов не создаёт дублей: уже перенесённые записи система пропускает. Следующий клуб с такими же отчётами пойдёт по уже проверенной карте полей.

## Образцы

Примеры пяти файлов с вымышленными данными лежат в папке «образцы_1С». Их можно загрузить в тестовой системе, чтобы посмотреть весь путь. Создать их заново можно командой `npm run import:samples -w apps/api`.
