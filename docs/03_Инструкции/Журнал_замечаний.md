# Журнал замечаний тестировщика

Нужен, чтобы тестировать CRM по ролям и записывать замечания и пожелания к каждой странице.

## Для тестировщика

- Внизу справа на любой странице есть кнопка **«Замечания»**. Она открывает окно журнала для этой страницы.
- Страница — это раздел вместе с выбранной вкладкой: «Финансы → Касса смены» и «Финансы → Долги» ведут разные журналы. Карточка клиента — одна страница на все карточки.
- Журнал привязан к странице и к роли: «Касса / управляющий» и «Касса / ресепшн» — разные журналы.
- Тип записи (необязательно): **Ошибка**, **Неудобно** или **Пожелание**. Текст обязателен.
- Скриншот можно вставить прямо в поле (на Маке снимок части экрана в буфер: ⌘⇧⌃4, затем ⌘V), приложить файлом или нажать «Снять экран».
- Сохранить — кнопкой «Сохранить» или ⌘ Enter.
- Если ушли со страницы с несохранённой записью, CRM спросит: «Сохранить ваши записи в журнале замечаний?».
- Под полем видны свои прошлые записи по этой странице и их статус: новое, в работе, сделано, не будем делать. Когда статус меняется, приходит уведомление в колокольчик.

## Для собственника

Раздел **Настройки → Журнал замечаний**:

- **Сводки по страницам** — разбор записей по смыслу для каждой страницы. Обновляется каждый день к 10:00 по Москве.
- **Все записи** — фильтры по странице, роли и статусу; можно выбрать записи и поменять статус с ответом тестировщику.
- **Тестировщики** — кому показывать окно журнала. Тестовые сотрудники отмечены сразу; настоящим сотрудникам клубов не включать.
- **Выгрузка** — ключ для ежедневного разбора (показывается один раз).

## Ежедневный разбор

Каждый день в 9:30 по Москве Claude забирает новые записи по ключу (`GET /api/test-notes/export`),
раскладывает их по смыслу, сохраняет сводку по каждой странице в CRM (`PUT /api/test-notes/export/summaries`)
и в репозиторий (`docs/05_Замечания/`), а к 10:00 присылает напоминание в чат проекта.
