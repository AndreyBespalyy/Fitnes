## Проверка безопасности (шаг 17)

| Что проверено | Результат |
|---|---|
| Изоляция клубов и сетей | Политики RLS в базе на всех таблицах с данными клиентов. Тест обходит код и проверяет саму базу |
| Вход | Только логин и пароль. Пароли хранятся в виде argon2. После 5 ошибок вход блокируется на 15 минут. Временный пароль нужно сменить при первом входе |
| Сеансы | Cookie httpOnly, SameSite=Lax, Secure на сервере. Веб-сеанс живёт 12 часов, мобильный — 30 дней. Можно завершить удалённо |
| Заголовки | CSP (только свои скрипты), X-Frame-Options, nosniff, Referrer-Policy, HSTS. Ответы API не кэшируются браузером |
| Секреты | Ключи касс, банков и мессенджеров зашифрованы и в интерфейс не возвращаются. .env в репозиторий не попадает |
| Внешние адреса | Push отправляется только в службы Apple, Google, Mozilla, Microsoft и Яндекса. Входящие от провайдеров принимаются только с секретом канала |
| Персональные данные | Телефон в списках маскируется. Полный номер выдаётся только кнопкой «Позвонить» с записью в журнал. Во внешние ИИ-модели данные не уходят (ТЗ 6.3) |
| Журнал | Изменить журнал аудита из приложения нельзя (тест «журнал аудита нельзя изменить») |
| Резервные копии | Ежедневно, хранятся 14 последних, доступ только у root. Копия за пределами сервера — на финальной стадии |

**Что остаётся до боевого запуска:**
- сменить общий демо-пароль;
- хранить копии на втором сервере или в облаке;
- подключить настоящие банк, кассу, WhatsApp, телефонию и турникеты (финальная стадия).
